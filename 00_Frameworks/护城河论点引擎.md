# 框架 · 护城河论点引擎

> **微观选名层(L3)**,坐在 [[瓶颈轮动框架]](宏观 L0–L2)**之下**、[[护城河论点-T]](实例模板)**之上**。
> 本文是「**怎么想**」;`护城河论点-T` 是「**往哪填**」(schema);deep-dive skill 是「**怎么执行**」(procedure)。三者别混。

> **一句话**:**price = 对未来的共识预期;财报只是把「产品竞争力 × 需求强度」兑现成现金。** 所以选名的核心不是预测新闻,是**在人群之前,从生意层面把护城河论点立住**。

---

## 0 · 为什么是这套(起点的错觉)

最初想以**新闻事件**为主轴做早期识别——失败了:新闻覆盖是**内生**的,在低覆盖的中小盘上**恰恰在你最需要早期信号时最稀薄**(LITE 在 2024–25 每月仅 7–22 条,成名后 2026 才 90–103 条)。

正解:**以护城河论点为主轴**。论点能从生意分析里、在共识结晶之前立住,**与新闻流无关**。INTC、LITE 都更符合这个描述,而非新闻驱动。

---

## 1 · 两层模型(整个引擎的骨架)

- **慢层 = 护城河论点** = 一条常驻假设,带**可证伪预言**(护城河若为真,必须命中的里程碑)。
- **快层 = 新闻 + 财报** = 对那些预先登记预言的**确认 / 否决票**。

这一拆解同时解掉三个老问题:

| 老问题 | 两层模型的解 |
|---|---|
| "一个事件是否决定性?" | = 它确认/打破了**哪条预言** |
| "早期新闻太稀,抓不到" | = 形成论点**根本不靠新闻** |
| "对真输家也能编出多头故事" | = 预先登记的可证伪预言会**对真输家公开失败**(反编故事护栏) |

---

## 2 · 核心模型:alpha = ① 与 ② 之间的那道缝

```
约束存在 → ① 约束被打破(早可见) → 窗口开(共识滞后) → ② 催化剂(共识结晶) → ③ 重定价
                         └──────────── 在这之间建仓 ────────────┘
```

- **① 见微知著 = 找到那条「绑定约束」(binding constraint)**:它一旦松动就重定价。特斯拉:产能→上海量产打破→放量→规模利润。"核心驱动" = **打破绑定约束的那件事**。
- **② 共识结晶需要催化剂**:基本面可早见,但市场信念只在催化事件上「啪」地到位。**大多数催化剂是排程型**(财报 / 交付 / 指数纳入 / FDA)→ 可预判 → **在它之前埋伏**。
- **alpha 就是 ①(基本面早可见)和 ②(共识结晶)之间的时间差。**

> 实证:INTC 盲测重建了完整链条——底部 $18(2025-04,最大悲观,早信号:新 CEO Lip-Bu Tan、NVDA/博通在测 18A、拆分价值托底)→ 催化① 政府入股传闻 → 催化② **NVDA $5B 入股 + "超大客户" 9-18(+22.8%)** → 催化③ **Q1 财报暴击 +23.6%** → +500%。无前视的 "as-of 2025-04" 卡片**预先点名**了后来兑现的里程碑(测试→签约客户)。

## 3 · 怎么挖出护城河:6 步法(深度的来源)

① **拆到稀缺层**——把产品拆到价值链**最细那层**,稀缺真正坐落处。
② 在那层问 **谁做不了 / 做不了什么 / 为什么**(良率 / IP / 生态锁定 / 资本 / 牌照)。
③ 行业浪让这条 moat **变深还是变浅**?
④ **对抗式**找最强空头 / 侵蚀路径(量化 + 时间线)。
⑤ **每个定性判断配一个数字**(分部收入 / 份额 / 毛利 / 客户承诺额)。
⑥ 映射到一个**类比范式**。

**脊柱招式:「不是 X,而是 Y」reframe。**
> LITE:不是"做光模块",而是那颗 **200G/lane EML 激光芯片**(中国能廉价组装模块,但这颗 InP 激光全球极少数能量产)。份额 50–60%、唯一量产 200G EML。

## 4 · 三个 🔒 必答(缺一不成卡)

| 🔒 | 必须回答 | 反例/招式 |
|---|---|---|
| **最强空头 / 侵蚀** | 点名 who/how + **量化侵蚀路径**(多少份额·毛利,多久)+ moat 指标**查斜率,不查快照** | LITE:Coherent 6 寸 InP 线 vs LITE 3 寸 |
| **共识 + 估值** | 反推 price-in 了什么增速/完美度 → **三档裁决**(§5) | 卖方目标价收敛 = 温度计,不是买点 |
| **可证伪预言 + 变体认知** | 预言带**数字/时间线** + 证伪触发;我和共识差在哪、**为什么我对**(没差异就老实写"复述共识") | COST:"利润全是会员费"已过时,第二引擎=Kirkland+SG&A 杠杆 |

> 三个 🔒 是**强制深度的护栏**:发不出卡 = 还没想清。它们同时挡住"给烂公司编多头"和"推荐已 price-in 满的好公司"。

---

## 5 · 三档裁决(引擎产出的顶点)

| 档 | 含义 | 样本 |
|---|---|---|
| **① 窗口开** | 被错杀的不对称机会(论点先于共识 + 便宜 + 生意可证) | **LITE** |
| **② 窗口关** | 好公司 ≠ 好买点,已 price-in | **ARM / COST** |
| **③ 未证·高方差** | moat 未证 + 结局二元 + 价格已假设中奖 = 彩票 | **CBRS;AMD/INTC 高位** |

⚠️ **moat-赢 ≠ 股票-赢**:估值已满时,预言全兑现也可能因倍数压缩而平庸(思科 2000 剧本)。

## 6 · moat 类型 → 预言模板(让"考卷"标准化)

不同 moat 类型,该**预先登记的预言**和**该盯的仪表盘**不同:

| moat 类型 | 稀缺机理 | 预先登记的预言 | 仪表盘指标 |
|---|---|---|---|
| 技术·良率型(LITE) | 工艺/良率几十年积累 | 守住良率 + 跟上晶圆制程 + 份额 | 良率、晶圆尺寸、EML 份额 |
| 生态锁定型(ARM) | 开发者 + 切换成本 | 锁定开发者 + 每芯片抽成率上行 | 开发者数、v9/CSS 渗透、版税率 |
| 规模经济型(COST) | 规模摊薄 + 续费 | 单位成本领先 + 会员续费 + 规模杠杆 | 续费率、单店模型、SG&A 率 |
| 资本·产能型 | 重资产壁垒 | 产能上量 + 单位成本下行 | capex、产能利用率、成本曲线 |
| 牌照·政策型 | 制度准入 | 审批通过 + 政策窗口 | 审批节点、政策时间表 |

## 7 · beat/miss × 容错度 = 实测 priced-for-perfection

**actual vs consensus(PG `earnings_quarter`)× 次日个股超额异动(DDB,stock pct − index pct)= 市场给这家公司的容错度。**

- miss 时跌越多 = price-in 越满 = 容错度越小。直接喂 §5 裁决。
- 实证 AMD:几乎季季 beat,但 2025Q4 营收 beat +6.2%/EPS beat +16% 次日仍 **−15.5%** → 容错度塌缩 = 极致 priced-for-perfection。
- 实证 COST:miss −1.8%→−6.8%、beat 几乎不奖 = 49x 下零容错。

## 8 · 输出契约(架构接口 —— 喂给快层模块)

慢层这套方法,**必须对外吐出两样东西**,它们是快层(财务/技术/新闻模块)的"考卷":

1. **`可证伪预言清单`**(每条带证伪触发)
2. **`监控仪表盘`**(3–5 指标 + 当前值 + 警戒阈值)

→ 新闻 / 财报 / 价格事件 = 给这些预言**投票**。这就是为什么模块不是 5 个独立智能体,而是**有向依赖**:护城河模块发考卷,其余模块答题。详见 [[公司跟踪系统]]。

## 9 · 诚实边界(纪律)

- **深度 = 源可达性 × 共识饱和度**:低覆盖/非共识名 → 真 edge(LITE);全覆盖名 → 只在**组织共识**(COST/ARM/AMD),此时价值在 **meta-裁决**(机会 vs 好公司)。**每次都要诚实说自己在出 edge 还是复述共识。**
- **走上游**:information value ∝ 1/传播距离。洞察靠一手(电话会/财报/S-1)+ 独立深度源;FMP 只供数字。**IPO <12 个月 → S-1 风险因素 = 最富的空头源。**
- **新闻内生**:别依赖第三方新闻量,靠 press-release + 财报 + 价格 + 独立专家研究。新闻**量**的异常本身 = 共识温度计信号。
- 每张卡永远留:**下一步该盯什么**。

---

## 10 · 接口:把新闻焊回论点

**falsifiability 是论点与实时流的接口。** 预言一旦登记,任何相关新闻/财报不再是孤立噪声,而是**对某条预言的一张确认/否决票**;同时反推"这条**本可以在什么时候**就知道"(早识别价值)。
> 这条接口让本框架(L3)与 [[瓶颈轮动框架]] 的事件流、未来的事件流模块无缝咬合。
